# MSTR

MSTR is an independent research and engineering project focused on building a fast, openly downloadable, local-first software-engineering model and system.

The repository begins in **preconstruction**. No backbone is selected, no model weights are admitted, and no long training run is authorized by this bootstrap commit.

The first governed workstream is **MSTR-000 — Interaction Contract + Base/Local/Speed Qualification**. Its purpose is to empirically freeze the coupled model/runtime/tool/edit contract before serious training compute is spent.
